03 · COMMAND

스킬은 주어지지 않는다.
직접 명령한다.

에고 웨폰에는 미리 정해진 스킬 목록이 없다. 계약자가 직접 소리로 명령하고, 무기가 그 행동에 성공하면 새로운 F급 명령으로 등록된다.

VOICE INPUT / CONTRACTOR ONLY “쫓아.”

COMMAND REGISTERED

쫓아 [F / 0%]

말 · 휘파람직접 발생시킨 음성 또는 소리만 인정

생각 · 문자 · 손짓명령 신호로 인정되지 않음

독립 성장웨폰 등급과 명령 등급은 서로 다르게 성장 가능

성능 한계명령이 강해도 현재 웨폰 자체의 물리적 한계는 넘지 못함
