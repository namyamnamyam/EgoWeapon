01 · WORLD

세계관 개요

스마트폰과 인터넷, 현대식 도시가 그대로 존재하는 2077년 한국. 달라진 것은 세계 곳곳에 게이트가 열리고 그것을 처리하는 헌터가 하나의 직업군으로 자리 잡았다는 점이다.

게이트가 일상이 된 지 50년

2027년 최초의 게이트가 나타난 뒤 인류는 마수, 마석, 코어를 연구하며 새로운 생존 체계를 만들었다. 2077년에는 게이트 대응과 에고 웨폰 운용이 전문 교육과 직업으로 정착했다.

2077헌터와 전문 아카데미가 게이트 대응 체계의 일부가 된다.

같은 등급표를 쓰더라도 대상의 의미는 다르다. 웨폰은 성장 수준, 명령은 해당 행동의 완성도, 게이트와 마수는 위험도를 나타낸다.

03 · GATE

게이트

내부에 마수가 존재하는 초자연적 공간. 동굴, 숲, 사막, 바다 등 내부 환경은 조사 전까지 확정할 수 없다.

BOSS

클리어

기본 클리어 조건은 보스 마수 처치. 내부 조사와 실제 공략 데이터를 통해 최종 등급이 확정된다.

1인 : 1에고 웨폰

하나의 에고 웨폰은 오직 한 명의 계약자만 가지며 계약자만 사용할 수 있다.

무기 계통 고정

같은 계통 안에서 진화할 수 있지만 다른 종류의 무기로 바꾸는 것은 불가능하다.

보관 형태

팔찌, 귀걸이, 목걸이, 라이터 같은 작은 소지품 형태로 변환해 휴대한다.

자율 움직임 제한

독립 생명체처럼 자유 이동하지 않는다. 활성 명령 수행에 필요한 움직임만 가능하다.

05 · COMMAND

명령

에고 웨폰에는 미리 정해진 스킬 목록이 없다. 계약자가 직접 만든 소리 신호를 무기가 성공적으로 수행하면 F급 명령으로 등록된다.

ARCHEON / COMMAND REGISTRATION
VOICE INPUT · CONTRACTOR ONLY
“쫓아.”
COMMAND REGISTERED
쫓아 [ F / 0% ]
말 · 휘파람계약자가 직접 발생시킨 음성 또는 소리 신호는 인정된다.
생각 · 문자 · 손짓소리 신호가 아니므로 명령으로 성립하지 않는다.
계약자 전용계약자 이외의 사람에게는 명령권이 없다.
성공해야 등록현재 형태와 성능으로 수행 가능한 행동이어야 하며 실패하면 등록되지 않는다.
독립 성장각 명령은 웨폰과 별개의 등급과 숙련도를 가진다. 단 실제 효과는 현재 웨폰 성능 한계를 넘지 못한다.
