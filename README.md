# Ego Weapon Academy — World Guide

`에고 웨폰 아카데미` 세계관 소개용 GitHub Pages 정적 사이트입니다.

## 구성
- 2077년 세계관 / 게이트 / 브레이크
- 에고 웨폰 코어와 자아 성장
- 자유형 `명령` 시스템
- 아르케온 에고 웨폰 아카데미
- 주요 인물 9명

## GitHub Pages
저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택하고 `main / (root)`를 지정하면 됩니다.

사이트 엔트리: `index.html`
